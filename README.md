# Agente para Estudiantes de TI

Repositorio con rutas de aprendizaje diseñadas para estudiantes de Tecnologías de la Información, enfocadas en computación en la nube, infraestructura, datos, automatización y habilidades profesionales.

## 📚 Rutas de Aprendizaje

Cada ruta está diseñada para:
- **4 horas por semana**
- **Actividades en formato micro-learning (20–30 min)**
- **Nivelado por experiencia** (Principiante / Intermedio / Avanzado)
- **Énfasis en:** nube, infraestructura, datos, automatización y habilidades profesionales

### Rutas Disponibles

| Nivel | Duración | Descripción |
|-------|----------|-------------|
| [🟢 Principiante](rutas-aprendizaje/principiante.md) | 8 semanas | Fundamentos sólidos en computación en la nube, habilidades digitales y lógica técnica |
| [🟡 Intermedio](rutas-aprendizaje/intermedio.md) | 8 semanas | Infraestructura, redes, seguridad y operaciones en Google Cloud |
| [🔴 Avanzado](rutas-aprendizaje/avanzado.md) | 8 semanas | Especialización en arquitectura en la nube, datos, automatización y soluciones escalables |

## 🎯 Objetivos Generales

- Desarrollar competencias técnicas en tecnologías de nube
- Preparar estudiantes para certificaciones de Google Cloud
- Aplicar conocimientos en proyectos prácticos
- Construir un portafolio de proyectos cloud

## 📖 Cómo usar este repositorio

1. Selecciona la ruta según tu nivel de experiencia
2. Sigue las actividades semanales en orden
3. Completa los mini-ejercicios y retos
4. Documenta tu progreso en el proyecto final

## 🛠️ Plataformas utilizadas

- [Google Cloud Skills Boost](https://www.cloudskillsboost.google/)
- [Google Cloud Console](https://console.cloud.google.com/)
- GitHub para control de versiones y documentación
